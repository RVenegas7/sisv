# capturas/ — Capturas del sistema heredado (Centuria)

Carpeta para las capturas de pantalla del sistema legado, usadas como **referencia** durante la revisión.

## Contenido

- `Pantalla Vigilancia.jpg` — captura del módulo de vigilancia (registro semanal de vigilancia epidemiológica).
- `OCR_Pantalla_Vigilancia.txt` — texto extraído de la captura (RapidOCR); guía de análisis.
- `README.md` — este archivo.

## Notas

- La prioridad de diseño será la **norma internacional** (OMS/RSPI, CIE, fichas estandarizadas) y las **normas y leyes venezolanas** de vigilancia epidemiológica; las capturas se usan de apoyo, no como fuente normativa principal.
